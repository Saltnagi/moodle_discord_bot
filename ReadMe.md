# 📚 Moodle通知Bot

Moodle（e-ラーニング）のカレンダーから**課題の提出期限や試験の予定**を読み取って、Discordの**DM（ダイレクトメッセージ）**でお知らせするBotです。
通知には、わかる場合は「**どの授業の予定か**」も一緒に表示されます。

| できること | 内容 |
|---|---|
| 🔔 新着の通知 | 新しい予定が追加されたら、10分以内にお知らせします |
| ⏰ 期限直前のリマインド | 提出期限の**1時間前**に、もう一度お知らせします |
| 📅 毎日の予定まとめ | 毎日**8:30と18:00**に、今後1週間の予定をまとめて送ります（時刻は変えられます） |
| 🎯 絞り込み | キーワードで「通知する／しない」を選べます。通知する期間も指定できます |

操作は、すべて **スラッシュコマンド**（`/` から始まるコマンド）です。チャット欄に `/` を入力すると、使えるコマンドの候補と説明が表示されます。

---

## はじめかた

### ① Botを自分のアカウントに追加する

運営者から渡された**導入リンク**を開き、「自分のアカウントに追加（Add to my apps）」を選びます。
**サーバーに参加する必要はありません。** 追加すると、BotとのDMを開けるようになります。

> 💡 すでにBotがいるサーバーに参加している場合は、そのサーバーのチャンネルからでも、そのまま `/使い方` を実行できます。

### ② MoodleのカレンダーURLを取得する

1. CNSのいずれかの授業から「e-ラーニング」を選び、Moodleへ移動します。
2. 右上のアイコンから「カレンダー」を選択します。
3. ページ下部にある「カレンダーをインポートまたはエクスポートする」を選択します。
4. そのページの「カレンダーをエクスポートする」を選択します。
5. 「エクスポートするイベント」は「**すべてのイベント**」、「期間」は「**最近及び次の60日間**」を選択します。
6. その状態で「カレンダーURLを取得する」を選択し、表示されたURLをコピーします。

### ③ Botに登録する

`/url 登録` を実行すると**入力欄が開く**ので、コピーしたURLを貼り付けて送信します。

> ⚠️ **このURLは「あなた専用の鍵」です。** 知られると、あなたの予定を他の人に見られてしまいます。
> 入力欄に貼り付けた内容は、他の人には見えません。チャンネルのメッセージとして送らないでください。

登録できるのは、大学のMoodleのURL（`https://` で始まるもの）だけです。登録に成功すると、使えるコマンドの説明が表示されます。

### ④ 通知してほしい予定を選ぶ（おすすめ）

登録した直後は、「期限」「試験」を含む予定だけが通知されます。授業名や「課題」「小テスト」などを追加すると、自分に必要な予定だけが届きます。

```
/フィルター 追加 単語:小テスト
/フィルター 追加 単語:線形代数
```

これで準備完了です。以後は自動でお知らせします。いつでも手動で確認したいときは `/moodle` を実行してください。

> 💡 `/使い方` は、URL未登録のときは「URLの登録方法」を、登録済みのときは「使えるコマンド」を表示します。

## どんな通知が届く？

予定は、次のような形で表示されます（授業名は【　】の中です）。

```
・[2026-10-08 23:59] 【線形代数】レポート1 の提出期限
・[2026-10-10 10:30〜12:00] 【情報工学】小テスト 試験
```

| 通知 | いつ届く？ | 見出し |
|---|---|---|
| 新着 | 新しい予定が見つかったとき（10分おきにチェック）。同じ予定は1回だけです | 定期通知：Moodle 新しい予定 |
| 期限直前 | 提出期限まで**60分以内**になったとき（予定ごとに1回） | ⏰ 提出期限が近い予定 |
| 毎日のまとめ | 毎日 **8:30** と **18:00**（日本時間） | 📅 定刻通知 |
| 手動 | `/moodle` を実行したとき | Moodle 予定一覧 |

- 登録した直後は、対象の予定がまとめて届きます（最初の1回だけ）。
- 期限直前の通知があるときは、その回は**期限直前の予定だけ**を送ります。新着の通知は次のチェックで届きます。
- 毎日のまとめは、予定が1件もないときは送られません。
- 開始と終了がある予定（開いている小テストなど）は、**終了の1時間前**にリマインドします。時刻のない「終日」の予定は、リマインドの対象外です。
- 授業名が分からない予定（Moodleに「2026UCS258」のような科目コードしか入っていない場合など）は、コードは表示せず、【　】も付けずに通知します。

## コマンド一覧

### 基本

| コマンド | 説明 |
|---|---|
| `/使い方`（`/help`） | 使い方を表示します |
| `/url 登録` | MoodleのカレンダーURLを登録・更新します（入力欄が開きます） |
| `/url 確認` | URLが登録済みかを確認します |
| `/url 削除` | URLと、すべての設定・通知履歴を削除します |
| `/moodle` | 今後の予定を今すぐ確認します |

### 絞り込み

| コマンド | 説明 |
|---|---|
| `/フィルター 一覧` | 登録中のキーワードを表示します |
| `/フィルター 追加 単語:◯◯` | その単語を含む予定だけを通知します |
| `/フィルター 削除 単語:◯◯` | キーワードを削除します（入力すると、登録済みの単語が候補に出ます） |
| `/除外 一覧` | 除外ワードを表示します |
| `/除外 追加 単語:◯◯` | その単語を含む予定を**通知しません**（フィルターより優先） |
| `/除外 削除 単語:◯◯` | 除外ワードを削除します |
| `/期間 確認` | 通知する期間の設定を表示します |
| `/期間 設定 日数:7` | 今後**7日以内**の予定だけを通知します（1〜365日） |
| `/期間 解除` | 期間の制限をなくします |

### 毎日の通知時刻

| コマンド | 説明 |
|---|---|
| `/通知時間 確認` | 現在の設定を表示します |
| `/通知時間 設定 時刻:8:30 18:00` | 時刻を変更します（最大4つ。スペース区切り） |
| `/通知時間 オフ` | 毎日のまとめを止めます |
| `/通知時間 初期化` | 初期設定（8:30 / 18:00）に戻します |

> 💡 設定は**ユーザーごと**に保存されるので、他の人には影響しません。

## 絞り込みのコツ

絞り込みは、**予定名・授業名・科目コード**に対して行われます（科目コードは通知に表示されなくても、絞り込みには使えます）。

- **フィルター**：どれかの単語を含む予定だけを通知します。**1つも登録していないときは、すべての予定が対象**です。
- **除外ワード**：どれかの単語を含む予定は通知しません。フィルターに一致していても除外されます。
- **期間**：今後◯日以内に始まる予定だけを対象にします。
- 大文字・小文字、全角・半角は区別しません（`Report` と `ｒｅｐｏｒｔ` は同じ扱い）。
- 単語は**50文字まで**、フィルターと除外ワードはそれぞれ**30個まで**です。

例：

```
/フィルター 追加 単語:課題        ← 「課題」を含む予定を通知
/フィルター 追加 単語:小テスト    ← 「小テスト」も通知
/除外 追加 単語:任意              ← 「任意」と書かれた予定は通知しない
/除外 追加 単語:UCS258            ← この科目コードの予定は通知しない
/期間 設定 日数:14                ← 2週間より先の予定は通知しない
```

> ℹ️ **期間は広げられません。** 登録したURLを発行したときの期間（「最近及び次の60日間」）より先の予定は、Botも取得できません。

## よくある質問

### 「/」を押してもコマンドが出ません

- Botを導入した直後は、コマンドが表示されるまで少し時間がかかることがあります。Discordを再起動（スマホはアプリを再起動）してみてください。
- サーバーのチャンネルで出ない場合は、そのチャンネルで「アプリコマンドを使用」が許可されているか、サーバーの管理者に確認してください。BotとのDMなら、この制限は関係ありません。
- それでも出ない場合は、運営者に連絡してください（コマンドの再登録が必要な場合があります）。

### 通知が届きません

次の順に確認してください。

1. **DMを受け取れる設定ですか？** Discordの「プライバシー設定」で、サーバーメンバーからのDMを許可してください。Botがメッセージを送れなかったときは、**120時間（5日）はそのユーザーへの送信を見送ります**。設定を直したあと、`/moodle` や `/url 登録` を実行すると、すぐ再開されます。
2. `/url 確認` で、URLが**登録済み**になっていますか？
3. `/moodle` で予定が表示されますか？ 0件のときは、「終了済み」「フィルターに一致しない」「除外された」「期間の範囲外」のどれが原因か、件数つきで表示されます。
4. URLは `https://` で始まる、大学のMoodleのものですか？

### `!moodle` のように「!」で始めても反応しません

コマンドは、「!」から「/」に変わりました。BotにDMで `!` から始まるメッセージを送ると、変更の案内が返ります。

### 授業名が表示されません

Moodleのカレンダーには、授業名ではなく「2026UCS258」のような**科目コード**しか入っていないことが多く、その場合は日本語の授業名が分からないため、コードは表示せず、【　】も付けずに通知します。個人の予定や、授業に紐づいていない予定でも同様です。

なお、表示されなくても、科目コードでの絞り込み（例：`/フィルター 追加 単語:UCS258`、`/除外 追加 単語:UCS258`）は使えます。

### 通知が多すぎる／少なすぎる

- 多いとき：`/フィルター` を絞る、`/除外` を使う、`/期間` を短くする
- 少ないとき：`/フィルター` のキーワードを増やす（すべて削除すると、全予定が対象になります）

### URLを変えたい・漏れてしまったかもしれない

Moodleでカレンダーのエクスポートをやり直してURLを取得し、`/url 登録` で登録し直してください（設定は引き継がれます）。

### 使うのをやめたい

`/url 削除` を実行すると、URL・フィルター・各種設定・通知履歴が削除されます。

### 時刻は何時の基準ですか？

すべて**日本時間**です。

## プライバシーと安全性

- **保存する情報**：DiscordのユーザーID、カレンダーURL、あなたの設定（フィルター・除外・期間・通知時刻）、通知済みの記録（予定の識別番号と日時のみ。予定の内容は保存しません）
- **扱わない情報**：Moodleのログインに使うIDやパスワードは、Botに入力する必要がありません
- **カレンダーURLの扱い**：Botを動かしている人のサーバー内のデータベースに保存されます（暗号化はしていません）。Botの運営者を信頼できる範囲でお使いください
- **URLの入力**：`/url 登録` の入力欄に貼り付けた内容は、他の人には見えません
- **返信の見え方**：サーバーや他の人とのDMでコマンドを使うと、返信は**あなたにだけ**見える形で表示されます。予定の内容が他の人に見えることはありません
- **アクセス先の制限**：Botがアクセスするのは、運営者が許可した大学のMoodleのサイトだけです

## 運営者向け：セットアップ

<details>
<summary>Botを自分で動かす人向けの手順（クリックで開く）</summary>

### 必要なもの

- Python 3.9 以上
- Discord Botのトークン
- **discord.py 2.4 以上**（ユーザーインストールに必要です）

```bash
pip install "discord.py>=2.4" icalendar requests python-dotenv tzdata
```

### 1. Discord Botを作る

[Discord Developer Portal](https://discord.com/developers/applications) でアプリ（Bot）を作成し、トークンを取得します。

**「Installation」タブ**で、次のように設定します。

- 「Installation Contexts」で、**User Install** と **Guild Install** の両方にチェックを入れます
- 「Default Install Settings」の Scopes を、次のようにします
  - User Install：`applications.commands`
  - Guild Install：`applications.commands` と `bot`

> 💡 **Message Content Intent は不要です**（スラッシュコマンドを使うため）。オフのままで構いません。
> 💡 他の人にも使ってもらう場合は、「Bot」タブの **Public Bot** が必要になることがあります（未確認）。

### 2. `.env` を作る

プロジェクト直下に `.env` を作り（見本：`.env.example`）、次の2行を書きます。

```
DISCORD_TOKEN=あなたのBotのトークン
MOODLE_ALLOWED_HOSTS=大学のMoodleのドメイン
```

- `MOODLE_ALLOWED_HOSTS` には、`https://` やパスを付けず、**ドメイン名だけ**を書きます（例：`moodle.example.ac.jp`）。カレンダーURLの `https://◯◯◯/…` の ◯◯◯ の部分です。複数ある場合はカンマ区切りです
- Botは、ここに書いたサイト以外のURLにはアクセスしません（セキュリティ対策）
- `.env` は **Gitに上げないでください**（`.gitignore` に入っています）

### 3. 起動する

```bash
python bot.py
```

- 設定に不足があると、ターミナルに原因と直し方が表示されて終了します
- 初回の起動時（とコマンドを変更した後の起動時）に、**スラッシュコマンドをDiscordへ自動で登録（同期）**します
- 起動すると、ターミナルに**導入リンク**が2種類（自分のアカウントに追加／サーバーに追加）表示されます。利用者には「自分のアカウントに追加」のリンクを配ってください

### スラッシュコマンドを変更したとき

コマンドの名前・説明・引数を変更したら、`config.py` の `COMMANDS_VERSION` の値を書き換えてください。次の起動時に自動で再登録されます。（毎回の起動で再登録するとDiscordの制限に当たるため、変更時だけ行います。強制したい場合は、`.env` に `SYNC_COMMANDS=1` を書いて起動します）

### 設定値（`config.py`）

| 名前 | 初期値 | 説明 |
|---|---|---|
| `CHECK_INTERVAL_MINUTES` | 10 | 新着・期限直前をチェックする間隔（分） |
| `REMINDER_BEFORE_MINUTES` | 60 | 期限の何分前にリマインドするか |
| `DEFAULT_NOTIFY_TIMES` | 08:30, 18:00 | 毎日のまとめの初期時刻 |
| `DIGEST_MAX_DAYS` | 7 | 毎日のまとめに載せる日数 |
| `DM_RETRY_HOURS` | 120 | DMを拒否されたとき、再送を待つ時間 |
| `DEFAULT_FILTER_WORDS` | 期限, 試験 | 新規ユーザーの初期フィルター |
| `MAX_WORD_LENGTH` / `MAX_WORDS_PER_LIST` | 50 / 30 | 単語の長さと数の上限 |
| `STATUS_MESSAGE` | `/使い方 で使い方を表示` | Botのステータス欄の表示 |
| `COMMANDS_VERSION` | （版の文字列） | コマンドを変更したら書き換える |

### ファイル構成

| ファイル | 役割 |
|---|---|
| `bot.py` | スラッシュコマンド、通知のループ処理 |
| `moodle.py` | Moodleからの取得、カレンダー（ICS）の解析、URLの検査 |
| `database.py` | データベース（SQLite）の操作 |
| `config.py` | 設定値、`.env` の読み込みと検査 |
| `.env.example` | `.env` の見本 |

### 運用上の注意

- **同じトークンのBotを、2か所で同時に動かさないでください。** 通知とコマンド応答が重複します。サーバーを引っ越すときは、古い方を止めてから、`moodle_bot.db` と `.env` を新しい場所へ移します
- `moodle_bot.db` にはユーザーのカレンダーURL（認証トークン入り）が入っています。他人に見られない場所に置き、バックアップも同様に管理してください
- 自動チェックでエラーが起きても、ユーザーにはDMせず、ターミナル（ログ）にだけ出力します。Moodleのメンテナンス中に通知が連投されることはありません
- **動作確認のお願い（未検証の点）**：Botとサーバーを共有していないユーザー（ユーザーインストールだけで使う人）に、Botから先にDM（通知）を送れるかは、公式資料で確認できていません。別のアカウントで、サーバーを共有しないままインストールし、`/url 登録` を実行して、受信テストのDMが届くか確認してください。届かない場合は、そのユーザーに警告が表示されます
